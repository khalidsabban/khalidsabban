## 🧠 LLM Fine-Tuning Research

**PyTorch · Hugging Face · Llama-2 · LoRA · QLoRA · NLP**

Research conducted at **Ulster University** exploring parameter-efficient fine-tuning of large language models.

### Research Areas

- Fine-tuning **Llama-2-7B**
- LoRA and QLoRA
- 4-bit quantisation
- Model validation
- Ablation studies
- Classification and Question Answering
- GPU memory optimisation

Experiments investigated how LoRA configuration requirements change across tasks including **SST-2 sentiment classification and SQuAD question answering**.
